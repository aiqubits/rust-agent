identity-preservation claim is made.

intentionally rejects the incomplete unreleased schema-1 record rather than treating absent
coexistence evidence bytes or reviewer policy as an implicit trusted default.

All Phase 1B implementation contracts above have named automated evidence. Tests marked ignored are
not omissions: the dedicated `Phase 1B Linux production gate` executes every one on an Ubuntu 24.04
runner with Landlock ABI 2, real user/mount/network namespaces, bubblewrap, pinned Cargo/rustc and
pinned wasm-bindgen. A host lacking those kernel facilities may establish compile/local-contract
evidence but cannot make a Linux production-support claim.
